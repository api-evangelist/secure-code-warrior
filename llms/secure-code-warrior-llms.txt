# Secure Code Warrior

> Secure Code Warrior (SCW) is the AI Software Governance platform that helps enterprises adopt AI-driven software development securely. The platform combines AI development visibility, commit-level risk correlation, and developer capability improvement — enabling organizations to govern AI-assisted and agentic development, reduce introduced vulnerabilities, and maintain traceability of AI activity for compliance and incident response.

Secure Code Warrior was founded in 2015 in Sydney, Australia. It serves over 600 enterprises globally, with 250,000+ developers trained on the platform. Notable customers include Mastercard, Capital One, Morgan Stanley, HSBC, Atlassian, IKEA, Verizon, Workday, Home Depot, and GE. The company is backed by investors including Paladin Capital and Goldman Sachs Investment Partners.

SCW is not a code scanning tool (SAST, DAST, SCA), a penetration testing service, a certification provider, or a consumer product. It is an enterprise platform focused on secure AI adoption and vulnerability prevention during development.
